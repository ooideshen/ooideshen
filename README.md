### 🌟 Featured Project

#### 🎓 [EduPath AI](https://github.com/ooideshen/Capstone-Project-EduPath-AI)
*An intelligent career & academic planning platform for SPM/UEC leavers, leveraging the RIASEC model and LLMs.*
- **System Architecture:** Decoupled architecture using `Next.js` for SSR/CSR frontend and `Spring Boot` for a robust RESTful backend.
- **AI Integration:** Orchestrated `OpenRouter AI` APIs with custom prompt engineering to generate deterministic, realistic career pathways and salary data based on user inputs.
- **Data Management:** Implemented secure Role-Based Access Control (RBAC) and managed relational data integrity using `PostgreSQL`.
